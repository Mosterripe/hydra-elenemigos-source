# 🚀 Hydra Launcher - Elenemigos Public Source

Esta es una fuente automatizada e inoficial para [Hydra Launcher](https://hydralauncher.site/) que agrega automáticamente los juegos publicados en **Elenemigos.com**.

## 📌 Características
- 🔄 **Actualización diaria:** Se sincroniza automáticamente todos los días a medianoche mediante GitHub Actions.
- 🔓 **Soporte para Pastebin:** Extrae directamente los enlaces de alojamiento real (Mediafire, Datavaults, Filekeeper, Vikingfile, Akirabox, Fileq, etc.).
- 🔑 **Clave integrada:** Incluye la contraseña de descompresión directamente en el nombre de cada juego.
